# Variance Analysis Framework

## Variance Convention
`Variance = Actual - Budget`

Positive variance = unfavorable overspend.  
Negative variance = favorable underspend.

## Review Levels
1. Company total
2. Department
3. Account
4. Department × Account
5. Month
6. Persistent variance across multiple months

## Management Thresholds
Suggested dashboard flags:
- > +10%: High attention
- +5% to +10%: Watch
- -5% to +5%: Near plan
- < -5%: Favorable / investigate underutilization
