# Source Provenance

This package is grounded in the public GitHub source data:
- `Fact_Marketplace_Orders.csv`: **90,000 rows**
- `Dim_Seller.csv`: **150 sellers**

The repository also contains `Dashboard.pbix`. The build environment used for this ZIP could confirm its presence on GitHub, but did not retrieve the PBIX binary into the generated package. No fake PBIX or placeholder has been added.
