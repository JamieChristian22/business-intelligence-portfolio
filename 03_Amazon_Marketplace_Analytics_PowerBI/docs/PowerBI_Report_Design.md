# Power BI Report Design

## Page 1 — Marketplace Overview
GMV, Orders, Units, Return Rate, Cancellation Rate, Rating, Top-10 Share; monthly GMV trend; GMV by tier and fulfillment.

## Page 2 — Seller Performance
Seller scorecard with rank, GMV share, cumulative share, return rate, cancellation rate, rating, tier.

## Page 3 — Concentration & Pareto
Cumulative GMV curve, Top 1/5/10/20 share cards, 80% threshold, seller exposure scenarios.

## Page 4 — Fulfillment Operations
FBA vs FBM GMV, orders, rating, returns, cancellations, GMV/order.

## Page 5 — Category Health
Category GMV, return rate, cancellation rate, rating, units.

## Page 6 — Long-Tail Growth
Long-tail seller count, GMV, median seller GMV, growth scenarios, underperforming seller opportunities.

Use synced Date/Tier/Category/Fulfillment slicers, drillthrough to seller detail, conditional formatting, and tooltip pages.
